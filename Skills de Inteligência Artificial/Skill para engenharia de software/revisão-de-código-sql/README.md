nome: revisão-de-código-sql
descrição: "Assistente universal de revisão de código SQL que realiza uma análise abrangente de segurança,
manutenibilidade e qualidade de código em diversos bancos de dados SQL (MySQL, PostgreSQL, SQL Server, Oracle).
Foca na prevenção de injeção de SQL, controle de acesso, padrões de codificação e detecção de 'anti-patterns'
(padrões de projeto inadequados). Complementa o prompt de otimização SQL, garantindo uma cobertura completa durante o desenvolvimento."
